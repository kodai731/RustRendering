# Vendored Python Wheels

This directory holds the Python wheels bundled into the Blender extension ZIP.
The wheels themselves are **not committed** (large, OS-specific). Only this
README and `HASHES.txt` (when populated) are tracked. Run
`scripts/collect_wheels.ps1` to populate this directory locally and in CI.

## What gets bundled

| Wheel | Purpose | Source |
|---|---|---|
| `thyllore_ml_core-0.0.1-cp310-abi3-{win_amd64,manylinux2014_x86_64,macosx_11_0_arm64}.whl` | L3 PyO3 wheel for Tier B (Curve Copilot) | `crates/thyllore-ml-core` via maturin |
| `grpcio-1.71.2-cp310-{win_amd64,manylinux2014_x86_64,macosx_11_0_arm64}.whl` | Tier A gRPC runtime | `pip download grpcio==1.71.2` |
| `grpcio_status-1.71.2-py3-none-any.whl` | grpcio sub-package, pure Python | same |
| `protobuf-5.29.6-cp310-cp310-{win_amd64,manylinux2014_x86_64,macosx_11_0_arm64}.whl` | grpc internal | same |
| `certifi-2024.12.14-py3-none-any.whl` | TLS root CAs | same |

`thyllore_ml_core` is `abi3`, so a single cp310 wheel covers Python 3.10+
(Blender 4.0 = 3.10, 4.2 = 3.11, future = 3.12).

## Reproducible collection

Run the helper script — it shells out to `pip download` and `maturin build`,
then writes a `HASHES.txt` manifest:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/collect_wheels.ps1
```

This populates **all three platforms** under `blender_addon/wheels/`. The
build script (`scripts/build_blender_addon.ps1 -Platform <p>`) prunes the list
to the active platform when staging.

## Hash manifest

`HASHES.txt` is regenerated by `collect_wheels.ps1`. CI compares the
post-download hashes against the committed manifest (run via
`scripts/verify_wheel_hashes.ps1`), failing if a wheel was tampered with.

## ABI marker handshake

`thyllore_ml_core` exports `__abi_marker__` (sourced from
`crates/thyllore-ml-api/src/lib.rs::ABI_MARKER`). The build script verifies
that this value matches `EXPECTED_ABI_MARKER` in `blender_addon/__init__.py`
**before** producing a ZIP, so a wheel update without an addon update is
caught at build time rather than at user-facing register time.
