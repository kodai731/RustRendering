# Purchaser Guide (Private Edition)

Welcome to the Thyllore add-on for Blender. This guide explains how to download
and install the private edition after purchasing on BOOTH.

The private edition needs **no license key, no activation, and no internet
connection**. It runs at full accuracy (ctx64) out of the box and never sends
any data — the add-on requests no network permission at all.

## 1. Download

1. Log in to [BOOTH](https://booth.pm) with the pixiv account you purchased with.
2. Open **My Page → Purchase History** (マイページ → 購入履歴).
3. Find the Thyllore add-on order and download the ZIP for your platform
   (Windows / Linux / macOS).

You can re-download the ZIP from your purchase history at any time — for a new
machine, after a reinstall, or after losing the file.

## 2. Install in Blender

1. Open Blender and go to **Edit → Preferences** (or press `Ctrl + ,`).
2. Select the **Add-ons** tab, then choose **Install from Disk...** from the
   drop-down menu in the top-right corner.
3. Select the downloaded ZIP and enable the **Thyllore Animation** add-on.

That is all — no further setup is required.

## 3. FAQ

### Do I need an internet connection?

No. The private edition works fully offline. It never contacts any server and
does not ask Blender for online access.

### Is my data private?

Yes, by construction. The private edition contains no network code paths for
telemetry or feedback records; nothing is ever transmitted.

### Can I use it on multiple computers?

Yes. Download the ZIP from your BOOTH purchase history on each machine you use.
Please do not redistribute the ZIP to others — see the EULA.

### What is "ctx64"?

The context length (ctx) is the amount of animation-curve context the Curve
Copilot model considers at once. The private edition always runs at ctx64, the
full accuracy tier.
